# پوشه admin

این پوشه برای قالب‌های سفارشی پنل مدیریت جنگو (Django Admin) در نظر گرفته شده است.

اگر خواستید ظاهر پیش‌فرض ادمین جنگو را شخصی‌سازی کنید، می‌توانید فایل‌هایی مثل
`admin/base_site.html` یا `admin/index.html` را همین‌جا اضافه کنید تا به‌طور خودکار
جایگزین قالب‌های پیش‌فرض جنگو شوند (کافی است در آن `{% extends 'admin/base_site.html' %}`
را بنویسید و مسیر پوشه‌ی `templates` در `TEMPLATES DIRS` تنظیمات شما ثبت شده باشد).

این فایل را می‌توانید حذف کنید؛ فقط برای این گذاشته شده که پوشه‌ی خالی در فشرده باقی بماند.
